# React Router Blog & Authentication Assignment
A simple React application demonstrating dynamic routing, list rendering, custom hooks, and simulated  authentication management using React Context.

## Features Implemented

- `AuthContext` managing real-time simulation of `isAuthenticated`, `login()`, and `logout()` state.
- Implemented a reusable `<ProtectedRoute>` component
- individual detail, login, and dashboard pages.

## Technologies used
- React
- TypeScript
- React Router DOM
- Context API
- Custom Hooks
- CSS
